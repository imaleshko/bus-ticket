# Комфорт Бус

Вебзастосунок для пошуку, бронювання та купівлі автобусних квитків.

## Технології

**Backend:**

- Node.js
- Express
- MongoDB (Mongoose)
- JWT

**Frontend:**

- React
- Vite

**Тести:**

- Cypress

## Можливості

- Реєстрація та авторизація
- Пошук маршрутів за напрямком і датою
- Вибір місця та бронювання квитка
- Особистий кабінет: перегляд персональних даних та куплених квитків
